# Дыхательный ритм

Таймер дыхания: фазы (вдох, задержка, выдох) с собственной длительностью и своими аудиозаписями, ротация звуков, длительность сессии, сохранённые варианты с подписями и бессрочная история.

- `www/index.html` — само приложение (один файл, работает без интернета).
- Android — обёртка Capacitor, APK собирается в GitHub Actions.
- Windows — обёртка Electron, установщик и portable `.exe` собираются в GitHub Actions.

Готовые файлы появляются в разделе **Releases** репозитория после каждой сборки.

Данные хранятся на каждом устройстве отдельно. Для переноса: вкладка «Варианты» → «Сохранить копию в файл», затем на другом устройстве «Загрузить копию».

Запуск на компьютере из исходников: `npm ci && npm run desktop`.
