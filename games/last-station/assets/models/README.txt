Модели башен (необязательно). Если файл есть — игра берёт его вместо процедурной модели.

  tower_archer.glb  — башня лучника
  tower_stone.glb   — камнемёт
  tower_cannon.glb  — паровая пушка

Модель автоматически масштабируется под клетку (ширина ~1) и ставится на землю.
Именованные узлы (необязательно) включают анимацию:
  aim / turret — поворачивается к цели (ось Y), «вперёд» = +Z
  arm          — рычаг камнемёта (вращается по X)
  barrel       — ствол пушки (откат по −Z)
  muzzle       — точка вылета снаряда
